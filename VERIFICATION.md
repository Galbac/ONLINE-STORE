## Исправлено во время проверки

1. Прокси Next.js перехватывал динамический обработчик `/api/session/[action]` и возвращал 404 при входе. Прокси перенесён в fallback, чтобы обработчики Next.js выполнялись первыми.
2. Подсчёт полного возврата учитывал ожидающие возвраты. Для статуса теперь суммируются только подтверждённые возвраты.
3. Тесты платежей и push обновлены под текущие контракты; номер платежа Robokassa проверяется по ID платежа вместо 0.

## Ограничения и оставшиеся проблемы

- **132 прежних падения тестов остаются.** Большинство сообщений связано с несоответствием заглушек текущим контрактам: нет session.info (73), store_id (20), external_1c_id (14), session.execute (6), for_update (5). Есть также ошибки моков SQLAlchemy, валидации query params и теста S3. Это не доказательство отсутствия ошибок в приложении: оставшиеся тесты требуют отдельного обновления и разбора.
- Браузер недоступен. Визуальная верстка, поведение React после обновления токена, реальные клики, клавиатура телефона и быстрый скролл не проверены. HTTP 200 не подтверждает корректность интерфейса.
- Не проверены доставка Web Push на устройство и работа Service Worker в браузере. Проверены API и принадлежность подписок.
- YooKassa проверялась с тестовыми ответами провайдера, без финансовых операций. Реальная оплата и возврат требуют проверки в тестовом магазине провайдера.
- Автоматический возврат Robokassa не реализован; оплаченные заказы обрабатывает менеджер.
- Конфигурация Nginx и Secure cookie на production HTTPS не проверялись на сервере.
